# Independent Computer — first executable increment
Open index.html in a modern browser; no server, workers, installation or network required. Original archives are in sources/. The catalog is a build-time extraction of all supplied archive entries; binary files retain metadata only. Runtime imports are individual text files, not ZIP expansion. Source inspection is lexical, not a full parser or semantic comprehension. Existing Klein computer is adapted to browser globals; original modules are unchanged. Original Node test: 8/8 passed. Browser-adapted engine executed sample and generated four paragraphs in Node VM; browser UI and MediaRecorder not device-tested. Address subdivision ports core.py, but placement requires operator evidence and no actual gate mapping is guessed. Local research searches source lines; no network research, autonomous coding, general JS execution, social network builder, or agentic reality builder yet. Media is symbolic vector artwork and animation, not general scene generation. Browser persistence uses localStorage and reports quota failures. Do not execute untrusted MESSY programs: synchronous execution can block the UI.
