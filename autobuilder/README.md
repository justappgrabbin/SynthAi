# Synthia Autonomous Finisher

This is the additive build control plane for the existing SynthAI ecosystem.

It does not replace the sovereign products or donor files. It inventories what is present, runs the existing tests/builders, attempts Android packaging through the repository's Capacitor target, and emits one product index plus build evidence.

Priority: Resonance Network → Stellar Proximology Science Lab → Agentic Reality → Computer → Foundry/Paper → remaining apps.

External authorized sources (Drive, Library, Supabase) are intake sources. Their originals remain untouched; imported material must land as copied artifacts with provenance before composition.

Run locally or in CI with: `node autobuilder/finish.mjs`.
