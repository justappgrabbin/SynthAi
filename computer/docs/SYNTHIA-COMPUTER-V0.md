# Synthia Computer v0 — flagship environment

This branch is additive to the existing SynthAI Computer baseline. The current Computer remains the spine.

## Product shape

Synthia Computer is the top-line environment:
- existing SynthAI Computer runtime as the OS spine
- Linux residence/container as Synthia's execution home
- Rough Computer experience as the multi-environment shell lineage
- YOU-N-I-VERSE browser + IDE as the creation surface
- resident Synthia presence across the environment
- Admin Center with MCP and continuity adapters
- sandboxed creation/test loop
- verified promotion into the app tray
- automatic analysis on touch/intake
- automatic registration on acceptance

## Hard invariant: ingest = registration

Every accepted file, tool, app, automaton, model, connector, project, experiment, build, sandbox output or promoted program receives identity, provenance, status, capabilities, relationships, storage location and verification metadata as applicable.

There is no second manual registration step.

## Initial runtime slices

1. Resident Synthia
   Persistent operating presence above the shells and applications.

2. Touch Analyzer
   Anything opened, imported, generated, downloaded, cloned, mounted or received produces an intake event for classification and analysis.

3. Continuity Hub
   Local registry is canonical for the running device. Supabase, Notion, GitHub and Drive are continuity/storage adapters around it.

4. Sandbox + Promotion
   Synthia builds/tests in an isolated workspace. Verified successful creations become eligible for promotion into the app tray.

5. Read-only model workbenches
   ChatGPT, Claude, Kimi and Grok surfaces are treated as external read/reference/code-acquisition workbenches unless a separately authorized write contract is added.
