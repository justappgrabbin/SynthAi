# Resonance Network Social Organism

Canonical base: `resonance-network-organism-2.zip`

This build keeps the organism intact and adds a social-first shell inspired by the supplied visual direction: dark cosmic field, violet/fuchsia glow, human-centered connection cards, project paths, resonance explanations, and a social feed.

The original system is not deleted. The active organism remains under `frontend/` + `backend/`, and donor packages are preserved under `preserved/`.
