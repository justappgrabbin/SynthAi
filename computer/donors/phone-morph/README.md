`surface-morph.js` is the unmodified supplied `runtime/morph-engine.js` from
`Synthia-Morph-Reskin-v0.1.0-3.zip` (Drive file
`1-YYq1j6u4k0vMuuF1_NL4P0bunv3IpC2`).

The phone adapter supplies core poses, a theme palette and the retained photo.
The donor engine handles landmark registration, mesh warping, surface completion
and persisted transition edges. These are skeletal image operations, not a
trained generative photo model. The adapter is `runtime/photo-avatar.mjs`.
