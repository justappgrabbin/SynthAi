# DesignPath — Human Design Path Network v1

Phone-first, local-first Human Design application assembled from the supplied Human Design, agent-builder, relationship/simulation, Genetic Matrix, and SynthAI Mesh materials.

## Run
Open `index.html` in a browser. For Acode, open this folder and Preview `index.html`. No install, backend, API key, npm, or LLM is required.

## Included now
- Local chart creation with gate/line/color/tone/base addressing
- 36-channel graph and defined-center derivation
- Type derived from channel connectivity (including motor-to-throat connectivity)
- Authority and profile
- Bodygraph-style center view
- Goal-specific Success Path engine
- Two-person electromagnetic/shared-gate comparison
- Living Experiment outcome log
- Local multi-person Design Network
- localStorage persistence
- SynthAI Mesh substrate included as `synthia-mesh-v1.js`

## Accuracy boundary
The bundled astronomical calculation is intentionally labeled as an approximation. It is useful for running the complete product flow offline, but it is not represented as Swiss Ephemeris-grade chart calculation. The supplied C# Human Design libraries are retained as source references in the source bundle, but are not silently translated into fake precision.
