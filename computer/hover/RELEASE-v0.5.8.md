# Release v0.5.8 — Solo Hover

This release wraps the v0.5.7 canonical Synthia organism and morph runtime in the Solo Hover application shell.

The persistent planet body opens Browser, Chat, World, To Do, and Build around one organism instance. Browser uses the preserved browser-hand runtime through a canonical adapter and can navigate, inspect, click, screenshot, fill approved form fields, and submit only after separate final confirmation. The Build surface retains the Foundry UI, the World surface reads organism state, and To Do persists locally.

No donor representation replaces the canonical 13-field Synthia address or the v0.5.7 embodiment morph path.
