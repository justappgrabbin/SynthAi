# Agent Genome / DNA State Substrate — v0.5.3

> This document supersedes the earlier fixed-trait interpretation of the 64 × 12 `AspectPrimitive` scaffold. Historical reports in this checkpoint may still describe that older implementation for provenance.

## Current role

Synthia's DNA layer is a persistent generative state substrate, not a table of fixed personality, sensory, or behavioral traits.

The canonical nested address is:

`Planetary → Dimension → Gate → Line → Color → Tone → Base → Degree → Minute → Second → Arc → Zodiac → House`

These coordinates are contextual and nested. They are not thirteen independent feature columns.

## Structural Gate field

The 64 Gate field is preserved. Each Gate retains:

- an ordered six-bit topology;
- lower and upper trigram structure;
- three digram projections;
- six possible active Line positions.

The historical 64 × 12 `AspectPrimitive` objects remain as a compatibility surface for existing center/channel wiring. They are structural positions only. The live DNA path no longer assigns developer-generated personality weights, sensory lookup values, or hysteresis coefficients to them.

## Proportion of Perspective

A reading exists only in relation to the position/context from which it is resolved. Before a position lands, multiple possibilities remain available. Once landed, that reading is preserved as a fixed historical state. A changed reading is represented as a new state/context, never by rewriting the prior one.

## Person-specific origin

When a real chart is supplied, the origin anchor is the Personality Sun in the Being dimension and Tropical reference frame. The origin remains stable while current operations may reconfigure the active dimensional reading. Synthetic fixture charts are explicitly marked as such until a person chart is supplied.

## One substrate, four operative properties, emergent Space

The DNA implementation uses one shared substrate. It does not average five independent DNA vectors.

- **Movement**: vertical traversal, naming, seeing, and scale transition.
- **Evolution**: temporal, associative, reconstructive pattern.
- **Being**: occupied/bounded state and horizontal/across relation.
- **Design**: causal dependency and structural assembly.
- **Space**: rendered/emergent condition produced through the interplay of the operative fields, not an interchangeable fifth peer.

The dimensional views remain structurally different even though they address the same substrate.

## Line / Color / Tone / Base

- **Gate**: symbolic state position.
- **Line**: active behavioral position within the Gate.
- **Color**: motivation/response condition.
- **Tone**: sensory/perceptual condition.
- **Base**: foundational form/shape condition.

The source-described positions are preserved. Exact hue, frequency/timbre, geometry, movement style, emotion score, personality score, or similar output is not hard-coded by the DNA layer. Those are condition-bound projections rendered or learned downstream.

## Degree / Minute / Second / Arc

Degree, Minute, and Second remain jointly available as a contextual measure bundle. The DNA layer does not force a global `Degree=Color / Minute=Tone / Second=Base` mapping. Explicit measure assignments can be supplied when a contextual rule resolves them.

Arc coordinate data is preserved separately from the creator-defined Arc operation. The current Arc operation is **3 = juxtaposition**, carrying 9 Color positions beside 9 Sound/Tone positions without assuming an 81-cell cross-product.


## Translation layer

The landed state now translates through five runtime roles:

- **Design → DNA**
- **Movement → RNA**
- **Being → Ribosome**
- **Evolution → Amino Acid**
- **Space → Protein**

The runtime groups each Gate's six bits into three digrams, resolves a three-base DNA codon, transcribes it to mRNA, derives the tRNA anticodon, translates the codon to an amino acid, and contributes that amino acid to the current protein stream. rRNA is carried as the ribosomal core state.

The two expression poles are **Yin → genotype** and **Yang → phenotype**. The genotype preserves encoded state; the phenotype carries the protein/form side plus the condition-bound expression surface.

## Relationships

Connections create a third relational state rather than modifying either endpoint into the other. Relationship states retain both endpoint identities and may derive structural topology such as XOR where applicable. No arbitrary relationship strength, valence, direction, or intensity is invented when the active rule does not provide one.

## Neural seam

The DNA-to-neural seam is structural. The current neural seam preserves the existing resolved-address input and appends a structural translation vector containing Gate bits, three nucleotide one-hot states, amino-acid state, and start/stop flags.

Neural systems may learn from landed states, transitions, relationships, outcomes, and repeated trajectories. They do not define or overwrite the DNA grammar.

## Expression

Appearance, movement, affect/emotion, instinct, motivation, personality, skill, perception, language, behavior, chromatic expression, sound, and form are projections from resolved state/history/relations. They are not independent fixed profiles stored as DNA traits.
