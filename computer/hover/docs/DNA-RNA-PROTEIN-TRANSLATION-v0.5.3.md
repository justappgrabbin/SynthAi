# DNA → RNA → Protein Translation Layer — v0.5.3

## Runtime mapping

The executable runtime uses the following dimensional roles:

| Dimension | Runtime role |
| --- | --- |
| Design | DNA |
| Movement | RNA |
| Being | Ribosome |
| Evolution | Amino Acid |
| Space | Protein |

The expression polarity is:

- Yin → genotype
- Yang → phenotype

RNA is represented through mRNA, tRNA, and rRNA. tRNA acts as the relational adaptor between an mRNA codon and the amino-acid state. The ribosome carries the situated translation event. Protein is the resulting assembled Space-state and carries phenotype projections from the same resolved condition.

## Gate translation path

Each Gate retains its six ordered binary positions. The runtime groups them into three digrams, resolves three DNA bases, transcribes T→U into an RNA codon, derives the paired tRNA anticodon, translates through the standard RNA codon table, and appends the resulting amino acid to the agent's current protein stream.

The Gate-to-digram alphabet used by this build is:

- 00 → T / U
- 01 → G
- 10 → A
- 11 → C

The same nucleotide also carries its phase representation and the three binary-property projections already discussed in the DNA research material.

## Integration

The translation layer does not replace the Proportion-of-Perspective state substrate. It consumes the landed state and returns genotype, RNA, ribosome, amino-acid, protein, and phenotype state attached to that same landed position.

Protein/phenotype state is carried into the machine-native perception record. Translation structure is appended to the existing neural input rather than replacing the existing channel, GNN, or neural-architecture path. Relational encounters also preserve both endpoint translations and create a third translation-relation state.

Skills and learning remain history-driven. Phenotype carries the current capability/skill state so learned state history can affect expression without rewriting the person's landed origin.
