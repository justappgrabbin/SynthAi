# SynthAI Computer — modular monolith
One Computer, not one file. The OS runtime is organized into core state/events/registries, storage/intake, execution fabric, experience/cultivation/morph/policy, shell/mutation wiring, macro adapters and independent micro identities.

Canonical macros: SynthAI Computer = OS; SynthAI2 = browser; SynthAI = hovering morph field; Synthia = game/world system; XynthAI = 18+ isolated system. Micro identities Prime, Venom, Echo, Celestial/Dream and Siren/Soft Core are deliberately registered with no macro assignment yet.

`ComputerRuntime.boot()` is the runtime entry. `/computer.html` is only a diagnostic shell connected to it, not the OS itself.

## Hover App Studio

Hover Build opens the preserved Paper App Studio at `/studio/index.html`. Its local file intake, function library, universal execution bridge, and standalone HTML export come from the user's existing Paper App Studio donor. The Tool Factory remains a separate live instrument in Build → Tools.
