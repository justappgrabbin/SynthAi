# Isohuman Unified-Field Architecture

## Core

There is one shared computational field.

Being, Design, Movement, Evolution, and Space are operator projections acting
on the same node-field. They are not separate stacked systems.

Each node contains a bounded local state space. Connections describe relational
topology; the internal state describes the node's possible transformations.

## MCP Hub

The MCP Hub carries typed events between:

- source material;
- user-specific state;
- chart calculations;
- transits;
- contact with complementary designs;
- background processes;
- the shared computational field;
- manifested outputs.

Each event retains its source, time, type, payload, and parent event.

## Sheldon Klein Tool Layer

This layer provides:

- AUTOLING-style language contact;
- DISEMINER-style relation observation;
- grammar observation;
- grammar-controlled expression;
- semantic path discovery;
- interaction history.

It uses the same shared semantic state as the rest of the application.

## Channel processing vocabulary

```text
Circuit       = family bias
Channel       = native processing behavior
Graph type    = topology
State space   = possible transformations
Changing line = metastable transition
Connection    = stable edge
```

The neural architecture attached to a channel is an analogue of its native
processing behavior.
