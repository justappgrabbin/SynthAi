# Synthia: current working system

This is an integration of the supplied Biverse Human Design application, its IsoHuman runtime, and the supplied Self-Discovery game's original storage and progression logic. The interface is English. A master birth configuration is calculated once from exact birth date, time, timezone and explicit place coordinates. Its natal tropical Sun is the central reference. All four chart frames are returned from that same calculation with a stable configuration ID. Personal chat and game selection use that configuration. Some original knowledge records remain Chinese internally; the local model must translate their relevant details faithfully, without replacing them with generic advice.

## One learning loop
Calculate a chart; inspect its structural facts; ask the personal chart-grounded agent to explain a specific item in English; choose a voluntary practice; record what happened; register and score a prediction before interpreting the outcome. The six research protocols describe how the proposed claims could fail. The protocols are available now; participant recruitment, automatic trial assignment, are not enabled in this interface. A chart-scoped prediction log is enabled: future forecast locking, append-only outcomes after the deadline, integrity hashes, and Brier scores against a baseline.

## Proportion of Perspective
Positions are reference coordinates; occupants move. Original events and observations stay fixed. Later interpretations append a new perspective and do not overwrite the historical event. Movement, Evolution, Being, Design, and Space are five named views. The four requested chart systems are explicit chart records with separate calculated placements and a common Personality Sun in Tropical anchor. They are not generic perspective labels or independent empirical observations. Gate and Hexagram are conventionally paired but their proposed operational distinction remains unresolved.

## Human Design
The supplied engine calculates gates, lines, colors, tones, bases, channels, centers, profile, type, and authority. These are calculations under a symbolic convention. Interpretation of personality, relationships or life purpose is not established scientific fact. Purpose is explored through the user's choices, values, and experience.

## Four chart frames
Tropical; draconic tropical true-node; draconic tropical mean-node; sidereal Fagan–Bradley. Mean draconic subtracts the polynomial mean ascending-node longitude. The node placements use the same chosen true or mean convention as their draconic offset. Fagan–Bradley uses an approximate J2000 offset and precession rate. Houses are equal houses. The same frame offset is applied to planetary longitudes, the ascendant, and house cusps; algebraic offset invariants are tested, while independent astronomical precision validation remains outstanding. Chart frames are not four independent observations. Birth-time uncertainty can change derived details.

## Personal agent
Chat receives only its selected chart, that chart's session history, and relevant original interpretation details. Ollama or llamafile provides actual language-model inference. The cultivated-self character is a reflective simulation with the same chart configuration, not a real alternate person or a predetermined ideal. It should support agency, acknowledge disagreement, and suggest measurable experiments. Missing model configuration produces an explicit unavailable error. The contact learner remains separate and its weights are not overwritten. Birth configurations and chart chat sessions persist in a local SQLite store. The original social service has its own account authentication. Linking that social identity to private chart access needs production integration; chart API routes are currently a local prototype.

## Self-discovery game
Original supplied mechanics: five categories (identity, purpose, connection, strength, dream); chart-derived Datababy word fragments (deterministic selection keyed by configuration and natal tropical Sun); fusion of 13 into a Gene Gnome sentence and a chart-derived archetype; level progression capped at 72. Browser-local progress is scoped by birth configuration and saved and can be cleared. Game coherence points are not health measurements. The agent is available after birth-chart creation regardless of level. Field Friend types and thresholds exist upstream but autonomous Field Friends are not connected in this integration. Reflection sentences can be discussed with the agent, but no personality diagnosis should be inferred from a game reward.

## Resonance and updates
The supplied semantic/contact graph remains available through the existing API. The supplied Computer and its original social server are connected: account registration, posts, projects, messages, and experiment observations. Chart-derived social matching, consent-based birth-chart sharing, and measured mutual connection are not yet integrated. It must separate chart similarity, self-reported experience, and observed outcomes. GitHub update checks can test changes; publishing an app update requires owner approval and configured repository/environment access. No self-modifying release or remote deployment has occurred.

## Data and local model
The phone browser talks to the app backend, which talks to the configured local model host. This does not mean the model runs on the phone itself. Public hosting needs authentication and private network configuration first. Browser-local game progress is unencrypted. Birth information must not enter release artifacts or public logs.
