# Integration boundary

This working server and phone client integrate the supplied Biverse Human Design app, IsoHuman calculator, Synthia Computer nine-field resonance operations and original Opportunity/Consent implementation. They are executable components, not nested archive exports. Runtime data, weights, node_modules, build outputs and archives are excluded.

The Android shell is adapted from justappgrabbin/Simlish commit 94e5395b1f230e87b864417c54e3e47dee93b358. Changes add a separate application ID, HTTPS server setup and server navigation while retaining the source's export and image-picker implementation. World tools are not part of the initial phone workflow.

SynthAi's existing Computer remains at repository root. Synthai2's browser and Simlish's world remain separate existing projects; they are not relabelled or overwritten. This integration branch adds `phone/` and its build workflow only. Run `phone/run_app.py` to use the active integrated app, rather than the existing root Netlify static site.

One canonical birth configuration supplies Tropical, Draconic Tropical True Node, Draconic Tropical Mean Node and Sidereal Fagan–Bradley. Their actual offsets remain distinct. The present astronomy approximations and hypothesis limits are disclosed in the app. Resonance is tested as a hypothesis, not asserted as scientifically established compatibility.

Development order: Human Design and opt-in resonance; stable private journey and model connection; then embodied world, agents and interactive science lab. The research protocols and forecast registry already run in the phone service.
