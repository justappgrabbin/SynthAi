This ledger treats the five Resonance Network source documents as acceptance requirements and the fourteen supplied ZIP projects as capability donors. Donors do not replace the canonical Computer, resident Synthia, worlds, State Space, relational mesh, or existing verified paths.

## Surface invariant

- **World View**: Computer surface using **Venom**, the lighter Computer-backed Synthia.
- **App View**: Computer surface using **Venom**, again relying on guaranteed host services.
- **Popup / Hover**: **Synthia Prime**, heavier because she cannot assume the Computer host is underneath her.
- A user's Synthia design controls the Synthia capability envelope. Computer host invariants stay separately available.
- A host service implemented for Venom is not automatically a Prime capability.
