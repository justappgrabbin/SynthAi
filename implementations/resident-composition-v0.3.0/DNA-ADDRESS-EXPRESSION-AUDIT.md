## Confirmed conflicts and limits

1. **Codon matrix coverage and overwrite:** executable inspection found gate 35 assigned to arginine and tryptophan, gate 44 assigned to glutamicAcid and valine. The reverse object silently selects the later assignment. Gates 5, 7, 9, 12, 25, 31, 33, 59, and 62 are missing.
2. **Conflicting donor dictionary:** `computer/donors/recovered/you-n-i-verse-corrected/gate_codon_dictionary.json` includes codon, amino_acid, biological_function, exaltation/detriment planets, hexagram keyword and core phrase. Gate 1 is Methionine there and lysine in the matrix. The owner confirmed on 2026-10-08 that Gate 1 should be lysine. This resolves the intended Gate 1 amino-acid choice in favor of the matrix entry; it does not establish that every other matrix entry overrides the dictionary. The conflicting recovered dictionary remains unchanged and needs reconciliation before it supplies runtime Gate 1 qualities.
3. **Numerical/model assumptions:** CHNOPS derives P as `3*N + 2*O + 5*S`; it is not a phosphorus count from the listed amino-acid formulas. Empty unit normalization yields nonfinite values, confirmed by executing the source. Resonance and deviation use fixed coefficients/thresholds. No new canonical strength/weakness law should be built from them without source reconciliation.
4. **Primitive vocabulary mismatch:** the inspected primitive-dimensions donor attributes all five written vowels primarily to Being through a phonetic hypothesis. The specification trace instead preserves I→Movement, A→Evolution, E→Being, U→Design, O→Space. Distinct namespaces/source versions must remain visible; deterministic attribution is not authority to erase the supplied vowel roles.
5. **Partial generation pipeline:** `generative-grammar.js` explicitly returns L3 as `NEEDS-DEFINITION (no numeric codon/isotope tables in source)` in its composed PL1 path. Its defaults and modality/planet slot choices are implemented mechanics, not verified complete chart/biological derivations.
6. **Address schemas diverge:** legacy `canonical-address-runtime/synthia-bridge.js` encodes zero-based micro/macro coordinates and computes fine coordinates using its own phase pipeline. The resonance OntologicalAddress computes ecliptic degrees, equal houses and a 0–59 ARC; its parser recomputes several supplied fields. The overlay requires sign-local degree 0–29, minute/second 0–59, arc 0–99, and preserves unresolved `arc`/`arcAxis` interop. These are not interchangeable address formats.
7. **Strength support is not enforcement:** profiles, tension and growth guidance exist, but the inspected host/tool paths do not enforce the personal-organism constraint that capability follows actually defined qualities. A shared repair capability must not be mistaken for a character's innate strength.
8. **Local/global identity:** `organism/IdentityBoundary.mjs` permits full local residence information but projects only hexagram identities/relations globally. Cross-host participation must respect this existing boundary rather than export full chart/composition records to any recipient.
9. **Missing baseline foundation:** the overlay imports `components/organism/state-space/state-space-foundation.mjs`, but that source is not in this GitHub tree. The supplied archive is needed for its complete implementation and integration tests. A similarly named recovered engine cannot silently substitute for it.

## Intended direction preserved

The corrected `HEXAGRAM-CHANNEL-STRUCTURE.md` retains five structural layers inside each hexagram and the thirteen-filter order. An incoming channel can arrive at Line, Color, Tone, Base, or Dimension and contribute a qualitative function. Three coherent nested dimensions are a stated transition requirement, not three edges or a guessed numerical score. Arrival-level function mapping, compatibility/coherence evaluation, local network transition, and loss of support remain unfinished requirements.

The next embodiment work should therefore reconcile the source vocabulary and encodings, retain named qualities with their address/source/epistemic status, then use existing shared compositions and addressed transformations to realize those qualities through a particular field's capabilities. Face references concern recognizable appearance; they do not replace the chart-derived structure. A page exposes fewer realization options than a world, but must preserve the underlying composition identity.

This experiment forwards existing composition/process-field snapshots and explicitly sourced names to authorized local host tools. It does not claim to have recovered DNA-to-letter formation, biological strengths, a complete chart resolver, dimensional coherence laws, or reference-image 3D embodiment. The source conflicts remain reviewable instead of being resolved through new arbitrary formulas.
