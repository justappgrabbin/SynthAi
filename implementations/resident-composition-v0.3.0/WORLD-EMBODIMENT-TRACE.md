# World embodiment state connection

User rule: visual references describe possible personal/public worlds, not a universal appearance. Persistent identity and underlying rules must support different world expressions.

The assembly now owns WorldEmbodiment, connecting the existing SemanticWorld, organism memory, morph expression and LivingWorldView. Each world carries its own authored expression and object actions. Local object actions change semantic facts, record before/after, preserve independent self-state, and optionally recover from a temporary interaction state. Authored qualitative data and address provenance are retained without invented defaults. World/session history and current state reload from memory. Active-world facts are isolated on entry.

LivingWorldView accepts a world-owned renderer. It receives the actual session and an interaction function that mutates state then re-renders. No universal avatar, style, species, or animation pack is imposed. Without an adapter the original organism rendering remains. This is state integration, not a completed visual world or photo-to-avatar generator.

Validation: 16 assembly tests pass; the added test checks persistent identity, distinct world expression, object occupancy/read-back, rejection of invalid repeat action, recovery, restart, world isolation and renderer interaction wiring.

Latest user clarification: qualitative rules apply across fields. Tone/Base are internal to the human; Line/Color appear to be the shared contact layers (Line reading awaits clarification of dictation). Crossing appears restricted to immediate above/below/side neighbors rather than skipping multiple positions; exact mesh interpretation awaits clarification/source resolution. This checkpoint implements local object interaction only and does not authorize arbitrary cross-human or cross-field contact. Cross-field eligibility, qualitative stability, source-address resolution, renderer restoration and animation assets remain open work. No arbitrary numeric quality metric or adjacency geometry was introduced.
