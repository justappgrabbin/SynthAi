# Mesh artifact generation checkpoint

The user requests modern Klein/MESSY systems with generative outputs beyond language, a pure JavaScript neural runtime, and their canonical morphological mesh. Start with the existing semantic world and AutoCoder rather than replacing the recovered systems.

`MeshArtifactGenerator` connects a supplied canonical resolver, a supplied generator, and behavioral verification to the existing `SemanticWorld`. It accepts an open output kind, purpose, source provenance, existing project files, and a generation parent. Unresolved interpretations are held before generation. Proposals retain their actual source files. Only a passing verification with evidence asserts a GENERATED fact. Failed and unverified attempts remain in persistent descendant history.

The injected proposer is the connection point for a JavaScript neural model; no trained neural model is bundled or claimed. The existing AutoCoder supplies project inspection. Its template synthesis is not neural learning. The supplied verifier must provide the execution isolation and behavior checks appropriate to the artifact. This module does not execute arbitrary proposals itself, deploy outputs, or train weights.

Validation: `node components/organism/tests/mesh-artifact-generation.mjs`. The test executes a known generated JavaScript function, checks a player reaches the other bank with identity intact, verifies unresolved input never reaches the proposer, and checks restoration, parent retention, and missing-evidence rejection.

Remaining work includes a concrete trained JavaScript neural proposer, canonical resolver integration following the user's source definitions, modernized style/contact rule producers, and full game/app/video output producers and interfaces. Gemini's rendition has not been provided; no missing canonical mappings have been invented.
